# Bugs & Drugs Tower Defense

BDTD: a tower defence game for Step 1 microbiology and antimicrobials. Pick the right drug for each bug, from the lungs to the CD4 ward.

Play: https://21veerakumare.github.io/lymph-node/

A study game for medical students, not medical advice. Facts cite First Aid for the USMLE Step 1 2025 by page; content is still being checked.

This repository holds only the built site for GitHub Pages. Source is private.
